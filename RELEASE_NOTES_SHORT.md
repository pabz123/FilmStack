# Release Notes - SHORT VERSION

## MovieFlix v1.0.0

**First official release!** 🎉

Transform your movie collection into a Netflix-style streaming experience.

---

### 📥 Download
- **MovieFlix_Lite_v1.0.zip** (85 MB)
- Requires VLC Media Player ([download free](https://www.videolan.org/vlc/))

---

### ✨ What's Included
- 🎨 Netflix-style interface
- 📊 Auto movie/series detection
- 🎬 Built-in video player
- 📡 Auto metadata & posters
- 🔄 Auto-next episode
- 💾 External drive support

---

### 🚀 Quick Start
1. Install VLC
2. Extract MovieFlix
3. Run MovieFlix.exe
4. Add movies to library folder
5. Scan and enjoy!

---

### 📋 Requirements
- Windows 10/11 (64-bit)
- VLC Media Player (free)
- 4GB RAM minimum

---

### 🐛 Known Issues
- Requires VLC installed separately
- TMDB API key needed for posters (free)
