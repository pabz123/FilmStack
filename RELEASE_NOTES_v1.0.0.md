## 🚀 Quick Start

1. **Install VLC** - Download from https://www.videolan.org/vlc/
2. **Download MovieFlix** - Get the ZIP file above
3. **Extract** - Unzip to any folder
4. **Run** - Double-click MovieFlix.exe
5. **Create Account** - Set up your local account
6. **Add Movies** - Copy movies to library folder
7. **Scan Library** - Click Scan in user menu
8. **Enjoy!** 🍿

## 🐛 Known Issues

- First launch may take 10-15 seconds (database setup)
- TMDB API key needed for poster fetching (free, instructions in README)
- Some antivirus software may flag the EXE (false positive - it's safe!)

---

## 💡 Tips

- **Naming Movies:** Use format: `Movie Name (Year).mkv`
- **Naming Series:** Use format: `Show.Name.S01E01.mkv`
- **Supported Formats:** MP4, MKV, AVI, MOV, WMV, and more
- **Get TMDB Key:** Free at https://www.themoviedb.org/ (for posters)
