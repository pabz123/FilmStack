# MovieFlix Quick Reference

## 🚀 One Command to Build

```batch
build_lite.bat
```

**Output:** `dist/MovieFlix_Lite_v1.0.zip` (~85MB)

---

## 📦 What You Get

- **Size:** 80-100 MB
- **VLC:** Not included (users download)
- **GitHub:** ✅ Fits perfectly!

---

## 🌐 Upload to GitHub

1. Go to: https://github.com/yourusername/movieflix
2. Click: Releases → New Release
3. Upload: `dist/MovieFlix_Lite_v1.0.zip`
4. Done! 🎉

---

## 👥 For Users

**Users need:**
1. Download MovieFlix from GitHub
2. Install VLC (https://videolan.org)
3. Run MovieFlix.exe
4. Works! ✓
